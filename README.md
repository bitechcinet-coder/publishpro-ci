# 🚀 PublishPro CI

**Plateforme de création de landing pages pour commerçants ivoiriens.**

Créez une page web professionnelle pour votre restaurant, boutique ou service en moins de 5 minutes. Optimisé pour le mobile et les paiements Mobile Money (Wave, Orange Money, MTN MoMo).

## Fonctionnalités

- 🎨 **Templates professionnels** : Restaurant, Boutique, Service
- 📱 **Responsive** : Design adapté aux mobiles (priorité Afrique)
- 💰 **Paiement Mobile Money** : Wave, Orange Money, MTN MoMo
- ⚡ **Déploiement instantané** : Votre page en ligne en 5 minutes
- 🔗 **Lien personnalisé** : `votre-commerce.publishpro.ci`
